# 恵庭サイモンズポイント会 公式ポータルサイト 制作プロジェクト

恵庭駅通商店街振興組合【事務局：株式会社北央商事】が推進する地域共通ポイント・CRM事業の
**公式ポータルサイト**（地域共通ポイントアプリへの「入口サイト」）制作プロジェクトのドキュメント一式です。

> このサイトの目的は、きれいなホームページを作ることではなく、**アプリ会員登録と加盟店利用につなげること**です。
