## 5. レスポンシブの挙動

| ブレークポイント | レイアウト |
| --- | --- |
| 〜599px（スマホ・最優先） | 全体1カラム。使い方3ステップは**縦積み（1列）**、加盟店カテゴリは**3列**。ナビはハンバーガー、画面下部に追従CTA。 |
| 600px〜 | 使い方3ステップを**3カラム**（アイコン上・テキスト下）に。 |
| 768px〜 | 加盟店カテゴリを**5カラム**（1行）に。 |
| 900px〜 | ヒーロー**2カラム**（コピー＋公式キャラクター）、使い方の右にキャンペーン告知／学生バナー、CTA行3カラム、ファイターズ・アプリ案内・お問い合わせも2カラムに。 |
| 1080px〜 | **グローバルナビをフル表示**（ハンバーガー・モバイル追従CTAは非表示）。ヘッダーに会員登録ボタンを表示。 |

- ナビのフル表示を1080px以上としているのは、項目数（6項目＋会員登録ボタン）に対して横幅に余裕がある場合のみ展開し、
  それ未満の幅では**ハンバーガー＋下部追従CTA**に切り替えて可読性とタップしやすさを確保するためです。
