# トップページ レイアウト（デザインモック）

**恵庭サイモンズポイント会 公式ポータルサイト**

ワイヤーフレーム（[03](03_トップページ_ワイヤーフレーム.md)）をもとに、**実際に動くトップページのレイアウトを HTML/CSS で制作**したものです。
配色・余白・タイポグラフィ・主要コンポーネントを含む「デザインの方向性」を確認するための**モック**です。

| 確認方法 | リンク |
| --- | --- |
| 🌐 ブラウザでプレビュー（GitHub Pages） | **https://playmark0227-svg.github.io/aipoint/** |
| 💻 ソース（HTML/CSS 一体・自己完結） | [site/index.html](../site/index.html) |
| 🖼️ キャプチャ | 本ページ下部 |

> プレビューURLは、本ブランチを push 後に GitHub Actions が自動デプロイして有効になります（数分かかる場合があります）。
> ※ 文言・写真・QRコード・各リンクはすべて**サンプル**です。確定素材（ロゴ・写真・QR・店舗情報）受領後に差し替えます。

## 2. デザインの考え方

指示書「7. デザイン方針」を反映しています。

| 方針 | 反映内容 |
| --- | --- |
| スマホ閲覧を最優先 | モバイルファースト設計。下層で1カラム、PCで多カラムに展開。画面下部に**追従アプリ登録ボタン**を常時表示。 |
| 高齢者にも見やすい | 本文 17px・行間広め・大きめのボタンとタップ領域・高コントラスト。 |
| 明るく、恵庭らしさ | 「花のまち／ガーデンシティ恵庭」をイメージした**緑（信頼・自然）＋オレンジ（元気・あたたかさ）**の明るい配色。 |
| 公共性と実用性のバランス | 広告的な派手さを抑え、情報の優先順位（登録→回遊→情報）を明確化。 |
| 日本語が安定するフォント | 游ゴシック／ヒラギノ／メイリオ系のシステムフォントを指定。 |

## 3. セクション構成（上から順）

指示書「6. トップページに必ず入れる要素」をすべて配置しています。

| # | セクション | 内容 | 必須要素との対応 |
| --- | --- | --- | --- |
| 0 | ヘッダー（追従） | ロゴ・ナビ・**アプリ登録ボタン** | 登録導線（常時） |
| 1 | ファーストビュー | **メインコピー「使うほど、恵庭が元気になる。」**／サブコピー／**アプリ登録ボタン＋QRコード** | ✅ メインコピー ✅ 登録ボタン/QR |
| 2 | 3つの導線カード | **加盟店を見る／クーポンを見る／ポイントの使い方** | ✅ 3導線 |
| 3 | ポイントの仕組み | 100円=1pt・1pt=1円／**地域内循環**の図解 | ✅ 地域内循環メッセージ |
| 4 | アプリ登録方法 | 無料・かんたん3ステップ＋CTA | 登録促進（KPI） |
| 5 | 加盟店一覧 | 飲食/小売/サービス/その他 カテゴリ | 加盟店利用 |
| 6 | クーポン・キャンペーン | 最新クーポン・スタンプラリー等 | 回遊・再訪 |
| 7 | お知らせ | 新着3件（事務局更新想定） | 鮮度・再訪 |
| 8 | 北海道文教大学連携 | 連携協定・学生参加プログラム紹介リンク | ✅ 大学連携リンク |
| 9 | 愛称投票・プレゼント | 公開時特設バナー | 公開時の参加促進 |
| 10 | お問い合わせ誘導 | フォームへの導線 | 問い合わせ数（KPI） |
| 11 | フッター | 事務局情報・**QR・SNS（Facebook/LINE/Instagram）**・プライバシーポリシー | SNS導線・信頼 |
| 12 | 追従CTA（モバイル） | 画面下部固定の**アプリ登録ボタン** | 登録機会の最大化 |

## 5. 本モックの位置づけ・次のステップ

- 本モックは**レイアウトと方向性の確認用**です。実装（WordPress化）は工程表のフェーズ3で行います。
- 確定後、下記を反映して本実装へ進みます。
  - ロゴ・ブランドカラー（→ 要件確認書 A-1）
  - 実写真・キービジュアル（→ A-3 / A-4）
  - 本物のアプリ登録QR・ストアURL（→ A-2）
  - 加盟店・お知らせの実データ（→ A-3 / C-3）
- ご確認いただきたい点：**配色・トーン**、**メインコピー周りの見せ方**、**掲載セクションの順序**。
