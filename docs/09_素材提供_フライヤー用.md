## 2. 先方にお伝えすべき注意点

| # | 内容 |
| --- | --- |
| 1 | **公式キャラクター**は、LINEでいただいた小さな画像（425×371px）しか手元にありません。フライヤーには**デザインされた方の元データ（ai・psd 等）**を使っていただく必要があります |
| 2 | 背景・アイコン・枠・スタンプは**同梱のPNGが最大サイズ**（ベクター形式の元データなし）。A4全面など大きく使う場合は高解像度化・描き起こしの相談が必要 |
| 3 | アプリ用QRと、本番URL確定後に作る**サイト用QR**を取り違えないこと（→ [08 公開準備チェックリスト](08_公開準備チェックリスト.md)） |
| 4 | 色は画面（RGB）と印刷（CMYK）で発色が異なるため、色校正で確認 |

## 3. あわせて行ったサイトの修正：公式キャラクターの色

受領したキャラクター画像は**印刷用の色形式（CMYK）**です（ピンク＝C0 M65 Y0 K4、文字＝K80）。
サイト組み込み時に単純な計算式でRGBへ変換していたため、**サイト上では紫がかったマゼンタ（#F456F4）**で表示されていました。

印刷用プロファイルを通して変換し直し、**印刷した時と同じピンク（#E87DAD）**にしました。
公式ロゴのピンク（#EB6EA5）と同系色になり、**フライヤー（印刷）とサイトでキャラクターの色が揃います**。

| | 修正前 | 修正後 |
| --- | --- | --- |
| キャラクターのピンク | #F456F4（紫寄り） | #E87DAD（ロゴと同系のピンク） |
| 「ポイントは、愛。」の文字 | #333333 | #606163（K80相当のグレー） |

- 対象：`site/images/character-official.png`（トップページのメインビジュアル・404ページ・ご説明資料）
- OGP画像（SNSでシェアした時の画像）と資料用スクリーンショットも撮り直し済み
