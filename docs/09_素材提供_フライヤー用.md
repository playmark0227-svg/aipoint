## 2. 先方にお伝えすべき注意点（説明書の1章に記載済み）

| # | 内容 |
| --- | --- |
| 1 | **公式キャラクター**は、LINEでいただいた小さな画像（425×371px）しか手元にありません。フライヤーには**デザインされた方の元データ（ai・psd 等）**が必要 |
| 2 | **スタンプラリー素材の女の子は、制作初期の仮キャラクター**（公式キャラクターではない）。フライヤーには使わない |
| 3 | 背景・アイコン・枠・スタンプは**同梱のPNGが最大サイズ**（ベクター形式の元データなし）。A4全面など大きく使う場合は高解像度化・描き起こしの相談が必要 |
| 4 | 背景の街灯の旗は「愛」の下の小さな文字が崩れている（装飾）。大きく使う場合は修正が必要 |
| 5 | キャンペーン枠の元データは市松模様（透過の見本柄）が描き込まれている → 白にした版を同梱 |

| 7 | 色は画面（RGB）と印刷（CMYK）で発色が異なるため、色校正で確認 |

## 3. あわせて行ったサイトの修正

### 公式キャラクターの色

受領したキャラクター画像は**印刷用の色形式（CMYK）**です（ピンク＝C0 M65 Y0 K4、文字＝K80）。
サイト組み込み時に単純な計算式でRGBへ変換していたため、**サイト上では紫がかったマゼンタ（#F456F4）**で表示されていました。

印刷用プロファイルを通して変換し直し、**印刷した時と同じピンク（#E87DAD）**にしました。
公式ロゴのピンク（#EB6EA5）と同系色になり、**フライヤー（印刷）とサイトでキャラクターの色が揃います**。
（印刷規格 FOGRA39 の実測データから求めた C0 M65 Y0 K4 の色との差は ΔE 約1で、見た目ではほぼ同じ色です）

| | 修正前 | 修正後 |
| --- | --- | --- |
| キャラクターのピンク | #F456F4（紫寄り） | #E87DAD（ロゴと同系のピンク） |
| 「ポイントは、愛。」の文字 | #333333 | #606163（K80相当のグレー） |

- 対象：`site/images/character-official.png`（トップページのメインビジュアル・404ページ・ご説明資料）
- OGP画像（SNSでシェアした時の画像）と資料用スクリーンショットも撮り直し
  （iPhone・Mac の表示に近い丸ゴシック体で撮影）
- ※PDF版のご説明資料・工程表・サイトマップ（旧版・差し替え予定）は未更新です

### 公式キャラクターの背景透過（9/30）

ヒーローの「ポイントは、愛。」入りキャラクターは、白い背景を「外周から白を塗りつぶす」方法で抜いていたため、

- 輪郭がギザギザで、**白いフチ（点線状）**が残っていた
- 「ポ」の半濁点の輪の中・「は」「愛」「。」の穴など、**文字に囲まれた白が抜けずに残っていた**

受領データ（CMYK）には**インクの量**がそのまま残っているため、「インクの量＝不透明度」として抜き直しました。

| | 修正前 | 修正後 |
| --- | --- | --- |
| 輪郭 | 透明／不透明の2段階（ギザギザ・白いフチ） | なめらか（半透明の階調つき）・白いフチなし |
| 文字の穴・半濁点の中 | 白のまま | 透明（背景が見える） |
| 目の白 | 残す | 残す（体の内側に白の下地を敷き、細い所も透けない） |
| 大きさ | 425×371px | **866×758px**（高精細画面向けに2倍。輪郭を整えて拡大） |
| 容量 | 約47KB | 約37KB |

- `tools/asset-pack/build.py --update-site` で作り直せます。書き出し時に「体の外に白い画素が無い」
  「目の白が残っている」「文字の穴が透明」「体の内側が透けていない」を自動で確認します
- 素材一式の `02_character/official-character_transparent.png` も同じものに差し替え（画面用。印刷には元データを）

### 未対応（要相談）

- **サイトのスタンプラリー画像（トップ・北海道文教大学連携ページ）にも、仮キャラクターの女の子が残っています。**
  公式キャラクターに描き替えるか、女の子の部分を外すかのご判断が必要です。

## 4. 作り直す手順（制作側）

```sh
npm i --no-save playwright-core @fontsource/zen-maru-gothic   # 初回のみ
python3 tools/asset-pack/build.py  <作業フォルダ> --date 2026-09-25   # 素材の取り出し・README作成
node    tools/asset-pack/render.js <作業フォルダ>                     # 画面撮影・README の PDF 化
python3 tools/asset-pack/build.py  --zip <作業フォルダ>               # ZIP 作成
```

- 作業フォルダはリポジトリの `site/`・`docs/` の外を指定（誤って消さないよう、ツールが作ったフォルダ以外は上書きしません）
- `build.py --update-site`：キャラクターのWeb用画像も書き換える／`render.js --site`：OGP・資料用スクリーンショットも撮り直す
- 必要なもの：Python3＋Pillow、CMYKプロファイル（`apt-get install ghostscript`）、日本語フォント（Noto Sans CJK 等）、
  Chromium、履歴を省略していない git（浅いクローンなら `git fetch --unshallow`）
- キャラクターの元データ（ai・psd）が届いたら、`02_character` を差し替えて作り直してください
