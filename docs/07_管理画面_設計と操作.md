# 管理画面（ヘッドレスCMS）設計・操作ガイド

**えにわ愛ポイント 公式ポータルサイト**

| 項目 | 内容 |
| --- | --- |
| 目的 | えにわ愛ポイント様が **お知らせ・加盟店を管理画面から追加・更新**できるようにする |
| 構成 | サイトは全てHTML（静的）／データのみ管理画面（ヘッドレスCMS）から取得 |
| 採用CMS | **microCMS**（日本語の管理画面・無料枠あり） |
| 対象 | ① お知らせ ② 加盟店 |

> **HTMLを触る必要はありません。** 管理画面にログインして入力・保存するだけでサイトに反映されます。
> パソコンでもスマートフォンでも操作できます。

---

## 1. 全体の流れ

```
えにわ愛ポイント様
      │  ① 管理画面にログイン
      ▼
 microCMS 管理画面
      │  ② 「お知らせ」「加盟店」を画面から入力して公開
      ▼
   公式サイト（HTML）
      │  ③ ページを開いたときにCMSから最新データを読み込んで表示
      ▼
      利用者
```

- サイト側は `site/assets/cms.js` がデータを取得して表示します。
- **CMSの設定前でも、サイトはサンプル内容で正常に表示されます**（表示が崩れることはありません）。

## 2. 管理画面で入力する項目

### 2-1. お知らせ（API ID：`news`）

| 表示名 | フィールドID | 種類 | 必須 | 説明 |
| --- | --- | --- | :-: | --- |
| タイトル | `title` | テキストフィールド | ✅ | 例：加盟店向け説明会を開催します |
| 日付 | `date` | 日時 | ✅ | 記事の日付（未入力の場合は公開日を使用） |
| カテゴリ | `category` | セレクトフィールド | ✅ | 説明会／イベント／新規加盟店／メンテナンス／キャンペーン |
| 本文 | `body` | リッチエディタ | | 記事の本文 |

> カテゴリは選択肢から選ぶだけで、サイト上のタグの色も自動で切り替わります。

### 2-2. 加盟店（API ID：`shops`）

| 表示名 | フィールドID | 種類 | 必須 | 説明 |
| --- | --- | --- | :-: | --- |
| 店名 | `name` | テキストフィールド | ✅ | 例：〇〇ベーカリー |
| カテゴリ | `category` | セレクトフィールド | ✅ | 飲食／小売／サービス／その他 |
| 所在地 | `address` | テキストフィールド | | 例：北海道恵庭市〇〇1-2-3 |
| 営業時間 | `hours` | テキストフィールド | | 例：10:00〜19:00（水曜定休） |
| 写真 | `photo` | 画像 | | 未登録の場合は「写真準備中」と表示されます |
| 地図リンク | `map` | テキストフィールド | | Googleマップ等のURL |

> **カテゴリは「飲食・小売・サービス・その他」の4分類**（ご支給原稿 7/18 準拠）。
> 加盟店ページの絞り込みボタンは、このカテゴリで自動的に動作します。

## 3. 事務局様の操作手順

### お知らせを追加する

1. microCMS の管理画面にログイン
2. 左メニューの **「お知らせ」** をクリック
3. 右上の **「＋ 追加」** をクリック
4. **タイトル・日付・カテゴリ・本文** を入力
5. 右上の **「公開」** をクリック → サイトに反映されます

### 加盟店を追加する

1. 左メニューの **「加盟店」** をクリック
2. 右上の **「＋ 追加」** をクリック
3. **店名・カテゴリ・所在地・営業時間・写真・地図リンク** を入力
   - 写真は画像ファイルをドラッグ＆ドロップするだけで登録できます
4. 右上の **「公開」** をクリック → 加盟店一覧に表示されます

### 内容を直す・消す

- 一覧から対象をクリック → 編集して「公開」で上書き
- 消す場合は編集画面の「…」メニューから削除

## 4. 制作側の接続設定（納品時に実施）

1. microCMS でサービスを作成し、上記2つのAPIを作成する
2. **APIキーを「GET（参照）のみ」の権限で発行**する
3. `site/assets/config.js` の `cms` の 2 か所を書き換える

```js
window.AIPOINT_CONFIG = {
  cms: {
    serviceDomain: 'YOUR-SERVICE-ID',   // ← microCMSのサービスID
    apiKey:        'YOUR-API-KEY',      // ← GET（参照）のみの権限で発行したキー
    newsEndpoint:  'news',
    shopsEndpoint: 'shops'
  },
  ...
};
```

> **API定義はインポートできます。** `docs/cms-schema/news.json` `docs/cms-schema/shops.json` を
> microCMS の「API設定 → スキーマ → インポート」から読み込めば、項目を手入力する必要はありません。

> ⚠️ **書き込み権限のあるAPIキーは絶対に設定しないでください。**
> 静的サイトのためキーはブラウザから見えます。参照専用キーであれば、
> 閲覧できる情報は「サイトに公開している内容」と同じ範囲に限られます。

### CMSを読み込んでいるページ

| ページ | 取得するデータ |
| --- | --- |
| トップ（`/`） | お知らせ 最新3件 |
| お知らせ（`/news/`） | お知らせ 最新20件 |
| お知らせ記事（`/news/article/?id=…`） | 記事1件（タイトル・日付・カテゴリ・本文） |
| 加盟店一覧（`/shops/`） | 加盟店 最大100件＋キーワード検索・カテゴリ絞り込み |

## 7. サイト設定ファイル（`site/assets/config.js`）

管理画面のほかにも、**このファイル1つ**でサイトの動作設定をまとめて行えます。

| 設定 | 項目 | 内容 |
| --- | --- | --- |
| `cms` | serviceDomain / apiKey | 管理画面（microCMS）との接続 |
| `forms` | contactEndpoint | お問い合わせフォームの送信先URL |
| | voteEndpoint | 愛称投票フォームの送信先URL |
| | fallbackMail | 送信先未設定時に案内するメールアドレス |
| `analytics` | ga4Id | Google Analytics 4 の測定ID（`G-XXXXXXXXXX`） |
| `links` | appDownload | アプリDLリンク（現在：`https://onelink.to/rmdmub`） |
| | facebook / line / instagram | SNSのURL |
| `office` | name / admin / tel / mail | 事務局情報 |

> **未設定でもサイトは正常に動作します。**
> - CMS未設定 → HTMLのサンプル内容を表示
> - フォーム送信先未設定 → 送信せず、メールでのご連絡を案内
> - GA4未設定 → 計測タグを読み込まない

### フォーム送信先について

静的サイトのため、フォームの送信には外部サービスを利用します。いずれかをご選択ください。

| 方式 | 特徴 |
| --- | --- |
| **Formspree** 等のフォームサービス | 設定が最も簡単。無料枠あり。送信内容がメールに届く |
| **Google Apps Script** | Googleスプレッドシートに蓄積できる。無料。投票の集計に適する |
| メールのみ（フォーム不使用） | 設定不要。`mailto:` でメールソフトが開く |

> 愛称投票は**集計が必要**なため、スプレッドシートに貯まる Google Apps Script 方式を推奨します（→ 確認事項 M-6）。

### アクセス解析で計測しているコンバージョン

| イベント名 | 内容 |
| --- | --- |
| `app_download` | アプリDL・QRコードのクリック（**KPI：アプリ会員登録数**） |
| `contact_send` | お問い合わせフォームの送信（**KPI：問い合わせ数**） |
| `vote_submit` | 愛称投票の送信 |
| `tel_click` / `mail_click` | 電話番号・メールアドレスのクリック |
