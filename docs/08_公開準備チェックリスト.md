## 3. QRコードについて（⑤の工程）

| 項目 | 内容 |
| --- | --- |
| 作成タイミング | **本番URL確定後**（A-4の確定が前提） |
| 内容 | 本番URL（例：`https://eniwa-point.com/`）を読み取れるQRコード |
| ご納品形式 | **PNG（Web・資料用）** と **SVG／EPS（印刷用・拡大しても劣化しない）** の両方 |
| ご確認事項 | ポスター・チラシ等に印刷される予定があれば、**サイズと余白**の指定をお知らせください |

> ⚠️ **注意**：現在サイトに掲載しているQRコードは、**アプリDL用（`onelink.to/rmdmub`）**です。
> 今回作成するのは**ポータルサイト用**のQRコードで、用途が異なります。
> 両者を取り違えないよう、ご納品時にファイル名で区別します。
> - `qr-app-*`：アプリダウンロード用（既存）
> - `qr-site-*`：ポータルサイト用（今回作成）

## 6. 補足：ゼンロジックでの設置について

- 本サイトは**静的HTML**のため、**PHP・データベース（MySQL）は不要**です。
  ファイル一式をドキュメントルートに置くだけで動作します。
- 設置するファイル：`site/` フォルダの中身一式（HTML・CSS・JS・画像）
- 必要な設定：
  - 独自ドメインの割当
  - **無料SSL（HTTPS）の有効化**
  - （任意）`http://` → `https://` への転送設定
  - （任意）404エラーページに `/404.html` を指定
- ご希望であれば、**制作側で設置作業まで対応**できます（A-1の情報が必要です）。
  高橋様が設置される場合は、**ファイル一式をZIPでお渡し**します。
