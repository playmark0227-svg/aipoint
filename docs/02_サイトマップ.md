## 1. 全体構成図（階層）

```
eniwa-point.com（トップページ）
│
├─ 1. トップページ（/）
│     キャッチコピー／アプリ登録導線・QR／加盟店・クーポン・ポイント説明への導線
│     地域内循環メッセージ／大学連携紹介リンク／お知らせ新着
│
├─ 2. ポイントとは（/about-point/）
│     地域共通ポイントの説明／100円＝1ポイント・1ポイント＝1円／地域内循環の仕組み
│
├─ 3. アプリ登録方法（/app-guide/）
│     Apple / Android 対応QRコード／登録手順／登録無料／個人情報の取り扱い
│
├─ 4. 加盟店一覧（/shops/）
│     カテゴリ別掲載：飲食 / 小売 / サービス / その他
│     店舗名・カテゴリ・所在地・営業時間・写真・地図リンク（Googleマップ）
│     ▼ 将来拡張：加盟店検索・店舗別詳細ページ
│
├─ 5. クーポン・キャンペーン情報（/coupon/）
│     最新クーポン／期間限定企画／スタンプラリー 等
│     ▼ 将来拡張：クーポン検索・カテゴリ別表示
│
├─ 6. お知らせ（/news/）
│     一覧（/news/）＋ 個別記事（/news/{id}/）
│     説明会・イベント・新規加盟店・メンテナンス情報
│
├─ 7. 北海道文教大学連携（/bunkyo/）
│     連携協定／学生参加プログラム／学生の参加メリット／地域での学び
│     ▼ 将来拡張：学生投稿記事・取材記事
│
└─ 8. お問い合わせ（/contact/）
      事務局名・電話・メール／問い合わせフォーム（加盟希望／利用者）
      └ 送信完了（/contact/thanks/）

【公開時 特設】プレゼント応募・愛称投票（/vote/ など）
      公開と同時に「ポータルサイト愛称」の投票に使用／応募完了ページ（/vote/thanks/）
```

## 3. 共通要素（全ページ）

### グローバルヘッダー
- サイトロゴ（→ トップへ）
- グローバルナビ：ポイントとは／アプリ登録方法／加盟店一覧／クーポン／お知らせ／大学連携／お問い合わせ
- **アプリ登録CTAボタン**（常時表示・最優先）
- スマホ時：ハンバーガーメニュー＋固定CTA

### グローバルフッター
- サイト名・事務局名（株式会社北央商事）・住所・電話・メール
- フッターナビ（全ページリンク）
- **SNSリンク**：Facebook / LINE / Instagram
- アプリ登録QRコード
- プライバシーポリシー（個人情報の取り扱い）

### 全ページ共通の常時導線（コンバージョン設計）
```
[ アプリ登録（QR/ボタン） ]  ← 全ページで常時アクセス可能（ヘッダー固定 or 追従）
```

## 4. ナビゲーション方針

- **グローバルナビ**：上記8ページ（主要導線）。
- **ユーティリティ**：アプリ登録CTAをナビ内で最も目立たせる。
- **モバイル**：画面下部または上部にアプリ登録CTAを追従表示し、回遊中も常に登録できる状態を維持。
- **パンくず**：下層ページに設置（トップ ＞ 各ページ）。
- **内部リンク設計**：トップ → 「加盟店を見る」「クーポンを見る」「ポイントの使い方」「アプリ登録方法」へ明確に分岐。
