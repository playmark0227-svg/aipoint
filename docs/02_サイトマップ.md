## 3. 共通要素（全ページ）

### グローバルヘッダー
- サイトロゴ（ハート＋「愛」マーク｜えにわ愛ポイント／ENIWA AI POINT → トップへ）
- グローバルナビ：ポイントとは／加盟店一覧／キャンペーン／ファイターズ／お知らせ／お問い合わせ
- **会員登録（無料）ボタン**（PC：ヘッダー右に常時表示）
- スマホ時：**ロゴ＋ハンバーガーメニュー**（会員登録は下部追従ボタン／メニュー内）

### グローバルフッター
- サイト名・「ポイントは、愛。」／事務局（恵庭駅通商店街振興組合・株式会社北央商事）
- フッターナビ：利用規約／プライバシーポリシー／特定商取引法に基づく表記／お問い合わせ／運営会社／よくあるご質問
- **SNSリンク**：Facebook / LINE / Instagram

### 全ページ共通の常時導線（コンバージョン設計）
```
[ 会員登録（無料）/ アプリ登録（QR） ]  ← PCはヘッダー、スマホは画面下部に追従表示
```

## 4. ナビゲーション方針

- **グローバルナビ**：上記の主要導線。会員登録CTAを最も目立たせる。
- **モバイル**：ヘッダーはロゴ＋ハンバーガー。画面下部に**会員登録（無料）の追従ボタン**を表示し、回遊中も常に登録できる状態を維持。
- **トップの分岐**：会員登録（無料）／アプリをダウンロード／使えるお店を見る を明確に提示。
- **パンくず**：下層ページに設置（トップ ＞ 各ページ）。
