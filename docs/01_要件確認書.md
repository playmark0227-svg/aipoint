## 1. 制作目的

恵庭サイモンズポイント会の公式ポータルサイトとして、以下を目的とします。

- 地域共通ポイントアプリの**登録促進**
- **加盟店情報**の発信
- **クーポン・イベント情報**の掲載
- **地域内消費の循環**促進

本サイトは、サイモンズのポイント・CRMシステムそのものを構築するものではありません。
利用者を**アプリ登録および加盟店利用へ導く「入口サイト」**として制作します。

### 最優先指標（KPI）

> サイトの「見た目」ではなく、下記の成果を最優先指標とします。

1. **アプリ登録数**
2. **加盟店利用**
3. **問い合わせ数**

## 2. 基本コンセプト

> **使うほど、恵庭が元気になる。**

地域のお店・飲食店・大学・利用者をつなぎ、ポイントを通じて地域内消費の循環を促進するサイトとします。

## 4. 制作範囲と役割分担

| 区分 | 役割 |
| --- | --- |
| **サイモンズ側** | ポイント付与、ポイント利用、会員情報、購買履歴、CRM分析等の基盤（本制作の対象外） |
| **ポータルサイト側（本制作）** | 加盟店情報、クーポン・イベント情報、アプリ登録案内、大学連携紹介等の情報発信 |

### 利用者の導線（コンバージョン経路）

```
利用者 → ポータルサイト → QRコード・リンク → アプリ登録 → 加盟店利用 → データ蓄積・CRM活用
```

> 本サイトの責務は **「ポータルサイト → QRコード・リンク → アプリ登録」** までを最大化することです。

## 7. デザイン方針

- 地域活性化、**親しみやすさ、信頼感**を重視する。
- **高齢者にも見やすい文字サイズ**とし、**スマートフォンでの閲覧を最優先**する。
- 色使いは明るく、恵庭らしさ・商店街らしさが伝わるデザインとする。
- 広告的に派手にしすぎず、**公共性と実用性のバランス**を取る。
- フォントは日本語表示が安定するものを使用する（メイリオ、游ゴシック等）。

### 制作側で想定するデザイン仕様（確認対象）

| 項目 | 想定値 | 備考 |
| --- | --- | --- |
| 設計基準 | モバイルファースト | スマホ閲覧を最優先 |
| 基本文字サイズ | 本文 16px 以上（高齢者配慮） | 拡大しても崩れない設計 |
| 配色 | 明るい地域色（要ブランドカラー確定） | ロゴ・既存配色に準拠 |
| 主要ボタン | アプリ登録CTAを最も目立たせる | 全ページ共通で常時露出 |
| アクセシビリティ | コントラスト比・タップ領域を確保 | — |

## 9. CMS・更新方法

- CMSは **WordPress を基本候補** とします。
  - 理由：更新しやすく、外注先が多く、加盟店情報やお知らせの追加に対応しやすいため。
  - 更新作業を極力簡単にしたい場合は、**STUDIO や Wix 等も比較対象** とします（→ 確認事項 C-1）。
- 納品時に、事務局向けの**簡易マニュアル**を作成します。
  - 「お知らせ更新」「加盟店追加」「画像差し替え」「QRコード差し替え」の4手順を収録。

## 10. 技術・インフラ要件

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| ドメイン | `eniwa-point.com` | 取得・DNS設定状況を確認（→ I-1） |
| サーバー | 北央商事で現在使用中のサーバーを利用 | **新たな費用が発生しないこと** |

> サーバーがWordPress要件を満たさない場合、STUDIO/Wix等の選定や構成変更が必要となるため、
> **着手初期にサーバー検証を実施**します（工程表 W1）。
